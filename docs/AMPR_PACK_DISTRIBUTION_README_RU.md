# AMPR Pack Tools для Windows

## Запуск

Запустите `ampr_pack_gui.exe`. Устанавливать Python, LZ4 или Visual Studio не
нужно. Рабочие файлы по умолчанию создаются рядом с программой в `work/title`;
пути можно изменить в окне.

GUI выбирает русский язык для русской системной локали и английский для всех
остальных. Язык можно переключить в верхней части окна.

Полная инструкция находится в `USER_GUIDE_RU.md`. Английские документы также
включены как `README_EN.md` и `USER_GUIDE_EN.md`.

## Что умеет программа

- объединять несколько пар `ampr_commands.bin` + `ampr_emu.index`;
- создавать TOML-профиль и отчёт по трассам;
- добавлять файлы, папки и маски, не попавшие в трассы;
- собирать паки AMPRPAK4 и отдельный `ampr_assets.index.crc`, проверять и
  инспектировать их;
- создавать `ampr_assets.index.runtime` из секции `[runtime]`;
- после повторной полной проверки удалять из выбранной `/app0` только файлы со
  статусом PACK.

Файл `.crc` нужен Python/GUI для offline-проверки и восстановления, но runtime
его не открывает и в память не загружает. Храните `.crc` вместе с резервной
копией соответствующего индекса и томов.

Трассы содержат только фактически выполненные APR-чтения и никогда не доказывают
полноту данных игры. До упаковки дополните профиль файлами и каталогами других
уровней, режимов, языков и DLC либо сознательно оставьте их loose. Сохраняйте
резервную копию оригинальной `/app0`.

Каталог `python-tools` — запасной вариант исходных инструментов. Он нужен только
для ручного запуска через Python 3.11+ и не используется автономным EXE.
